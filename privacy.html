토지한눈

개인정보처리방침

토지한눈은 필요한 정보만 최소한으로 처리하며 회원가입이나 광고 추적 기능을 사용하지 않습니다.

시행일 2026년 10월 12일

1. 처리하는 정보

토지한눈은 이름, 전화번호, 이메일, 주민등록번호 등 사용자를 식별하는 개인정보를 직접 수집하거나 서버에 저장하지 않습니다.

  • 검색어와 선택 필지: 토지정보 조회를 위해 VWorld 공개 API 요청에 사용됩니다.
  • 관심 토지: 사용자의 브라우저 로컬 저장소에만 보관됩니다.
  • 현재 위치: 사용자가 기능을 선택하고 브라우저 권한을 허용한 경우 지도 이동에만 사용되며 서버에 저장하지 않습니다.

2. 이용 목적과 보유기간

처리 정보는 주소·지번 검색, 지도 표시, 토지·건축물 공개정보 조회, 관심 토지 표시를 위해서만 사용합니다. 서버는 조회 내용을 별도 데이터베이스에 보관하지 않으며, 관심 토지는 사용자가 브라우저 데이터를 삭제할 때까지 해당 기기에 남습니다.

3. 외부 서비스 제공

토지한눈은 조회 기능을 제공하기 위해 VWorld 공간정보 오픈플랫폼과 통신합니다. 상세 화면의 정부24, 토지이음, 인터넷등기소, 세움터, 국토정보플랫폼, 화성특례시청 링크를 선택하면 각 기관의 개인정보처리방침이 적용됩니다.

4. 저장정보 삭제 방법

관심 토지는 상세 화면의 별표 버튼으로 개별 삭제할 수 있습니다. 전체 삭제는 브라우저 설정에서 이 사이트의 로컬 저장소 또는 사이트 데이터를 삭제하면 됩니다.

5. 안전성과 이용자 권리

API 인증정보는 브라우저에 공개하지 않고 서버 환경변수에서 관리합니다. 사용자는 위치 권한을 거부할 수 있으며, 거부해도 주소·지번 검색과 지도 조회 기능을 사용할 수 있습니다.
