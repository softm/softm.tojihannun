# 토지한눈

`돌봄한눈`의 지도 중심 UI와 쉬운 선택 흐름을 토지대장 조회에 맞게 재구성한 반응형 웹 앱입니다. VWorld 지도·주소 검색·연속지적도를 연결하고, 선택한 필지의 VWorld 데이터만 상세 화면에 표시합니다.

- 영문 프로젝트명: `Land at a Glance`
- 폴더명: `softm.tojihannun`
- npm 패키지명: `land-at-a-glance`
- 운영 도메인: `https://tojihannun.designboard.net`

## 실행

의존성을 설치하고 로컬 서버를 실행합니다.

```bash
npm ci
cp config.example.js config.local.js
npm start
```

브라우저에서 `http://localhost:4173`을 엽니다.

`config.local.js`의 `vworldApiKey`에 VWorld 인증키를 넣고, VWorld 콘솔에서 키의 인증 도메인을 `localhost`로 등록해야 합니다. 이 파일은 Git에서 제외되며 브라우저에 정적으로 제공되지 않습니다.

## 배포

운영 환경에서는 저장소에 인증키를 올리지 않고 다음 환경변수를 설정합니다.

```bash
VWORLD_API_KEY=발급받은_키
VWORLD_DOMAIN=tojihannun.designboard.net
```

Node.js 배포에서는 실행 명령 `npm ci && npm start`와 환경변수를 사용하며, 서버의 `/api/vworld/*` 프록시가 인증키를 대신 전달합니다.

GitHub Pages 정적 배포에서는 등록 도메인 전용 VWorld 브라우저 키와 JSONP를 이용해 검색·데이터 조회를 수행합니다. 키가 다른 도메인에서 동작하지 않도록 VWorld 인증키 관리에서 `tojihannun.designboard.net`만 허용해야 합니다. 브라우저용 라이브러리는 버전을 고정한 jsDelivr CDN에서 불러옵니다.

## 포함 기능

- 도로명·지번 검색 및 자동 완성
- 일반·위성·위성+지적도 지도 전환
- 연속지적도(WMS) 표시와 지도 클릭 필지 조회
- 토지·임야대장 공개정보(지목, 면적, 대장구분, 축척, 소유구분) 발급 없이 조회
- 개별공시지가, 토지특성, 토지이용계획, 토지이동 이력 표시
- PNU 기반 토지이음 연동
  - 소재지·지목·면적
  - 국토계획법 및 다른 법령에 따른 지역·지구 지정정보
  - 지역·지구별 행위제한 근거 법령
  - 선택 필지를 토지이음 공식 상세화면으로 POST 연결
- VWorld 건축물 요약정보 및 국토교통부 건축물대장 원문 iframe 보기
- 토지이음·인터넷등기소·정부24·세움터·국토정보플랫폼·화성특례시청 공식 사이트 연계
- 관심 토지 로컬 저장
- 선택 필지 상세정보를 정돈된 보고서로 다운로드
  - PDF 인쇄용 보고서
  - DOCX 편집 가능한 문서
  - HWPX 한컴오피스 표준문서
  - PPTX 발표용 슬라이드
  - PNG 고화질 긴 이미지 / JPG 공유용 이미지
- 정부24 공식 열람·발급 페이지 연결
- 운영용 개인정보처리방침 페이지

공개 API에서는 소유자 성명·주소·등록번호·지분 등 개인정보를 제공하지 않습니다. 화면의 데이터는 참고용이며, 전체 내용이나 법적 증명이 필요하면 정부24에서 공식 열람·발급해야 합니다.

보고서에는 공개 API로 조회한 필지 기본정보, 토지대장 공개정보, 토지이음 지역·지구 및 행위제한 근거, 개인정보를 제외한 소유 현황, 토지이동 이력, 건축물 요약정보가 포함됩니다. 한글 문서는 구형 바이너리 `.hwp` 대신 공개 표준 포맷인 `.hwpx`로 생성합니다.
