# 실거래 가격 비교 재설계 — 2026-11-17

## 1. 이번 요청과 결정
사용자가 제공한 화면에서는 전용 약 60·85·103·121㎡의 19건을 합산한 매매총액 카드와 만원/㎡ 차트를 동시에 표시했다. 따라서 카드의 금액과 그래프의 숫자를 직접 비교할 수 없었다. 이전의 차트 우선 배치 요구보다 이번의 `가격 요약 → 같은 기준의 차트` 요구를 우선한다.

외부 공인중개사나 감정평가사에게 실제로 자문을 의뢰한 기록은 없다. 이 문서는 부동산 비교·제품 기획·데이터 검증의 관점으로 공식 자료를 검토해 정한 제품 설계이며, 자산가치 감정이나 투자 권유가 아니다.

## 3. 단일 비교 기준
`조회 지역/지번 × 부동산 유형 × 조회기간 × 전용면적대 × 가격 표시 기준`을 하나의 화면 상태로 유지한다. 이 상태에서 선택한 거래 집합을 카드·차트·목록이 동일하게 사용한다. 페이지 이동은 목록 표시만 바꾸고 차트·요약의 전체 표본은 바꾸지 않는다.

### 전용면적
- 아파트·연립/다세대·오피스텔: 실제 공개 전용면적을 1㎡ 구간으로 묶는다. 84.97㎡와 84.99㎡는 `전용 84㎡대 (실제 84.97~84.99㎡)`이다. 84.97㎡를 반올림해 `85㎡형`으로 부르지 않는다.
- 첫 진입 시 거래가 가장 많은 면적대를 선택한다. 동률이면 최신 계약일이 있는 면적대를 선택한다. `거래가 많은 면적 자동 선택`을 표시한다. 사용자의 보유 주택 면적을 추정한 결과가 아니다.
- 면적대는 같은 평면/동/층/향을 보장하지 않는다. 다수 면적대는 추가 선택 메뉴에서 빠짐없이 선택할 수 있으며, 여러 면적을 `기타` 하나로 합쳐 가격 추세를 만들지 않는다.
- 전체 면적을 명시적으로 선택하면 혼합 분포임을 안내하고 월별 중앙값 연결선을 숨긴다.
- 토지·상가·단독·공장 등은 아파트 전용면적 로직을 억지로 적용하지 않는다. 기존 유형별 면적 정의를 유지하고, 토지는 면적당 가격을 기본으로 한다. 지목·용도·도로조건 등 미조정 차이를 가격지수로 해석하지 않는다.

### 가격 단위
| 선택 | 카드·차트·목록의 주표시 | 계산 |
|---|---|---|
| 매매총액 (주거 기본) | 원 단위 금액, 억/만원 가독성 표시 | 신고 거래금액 그대로 |
| 면적 ㎡당 가격 | 만원/㎡ | 각 거래금액 ÷ 해당 거래의 면적 |
| 면적 3.3㎡당 가격 | 만원/3.3㎡ | 각 거래금액 ÷ 해당 거래의 면적 × 3.3 |

`3.3㎡당`을 정확한 1평 단위로 가장하지 않는다. 특히 아파트 단가는 전용면적 기준이며 공급면적 기준 평당가가 아니다. 단가 모드에서 원래 계약 총액은 거래목록에 명확한 보조 라벨로 남긴다. 단가 중앙값은 각 거래의 단가를 계산한 뒤 중앙값을 구한다. `중앙 총액 ÷ 중앙 면적`으로 대신 계산하지 않는다.

## 4. 화면 순서
1. 유형·기간 및 해당 지번/같은 법정동 선택.
2. 전용면적 선택과 가격 기준 선택, 실제 비교 조건 한 줄.
3. 두 줄 네 카드: 최근 계약금액/단가, 대표값(중앙값), 조회기간 최저~최고, 비교 표본 수·실제 계약기간.
4. 기본 펼침 차트: 같은 단위의 월별 중앙값 및 최저~최고 범위. 점을 터치하거나 키보드로 선택하면 하단에 월·건수·가격·범위가 표시됨.
5. 거래목록: 한 페이지 10건, 최대 5개 페이지 번호, 이전/다음 유지.

## 5. 통계·신뢰성 규칙
- 최근 계약일에 여러 계약이 있으면 임의 한 건 대신 그날의 가격 범위와 건수를 표시한다.
- 중앙값을 `가격순으로 놓았을 때 가운데 값`으로 설명한다. 1건·2건 월은 표본 적음을 표시하고 상승/하락 판단을 붙이지 않는다.
- 차트 세로축 기본 0. 자동으로 축을 잘라 작은 가격 차이를 크게 보이게 하지 않는다.
- 달력상의 빈 월은 가격 0이 아니다. `표시 자료 없음`으로 처리하고 연결선을 끊는다.
- 전체 면적 혼합에서는 연결선을 숨긴다. 주거 기본 화면은 단일 면적대만 보여준다.
- 취소 거래, 가격/면적 미확인, 분산 자료 연결 실패는 거래 0건·정상 수집으로 포장하지 않는다.
- 지번별 실제 거래와 같은 법정동 비교를 섞지 않는다. 후자는 거리순도, 동일 단지도 아니다.
- 자료는 신고 계약금액의 분포이며 공식 가격지수·감정가·현재 매물가격이 아니다.
- 화면 표시만 변경하며 신규 공공 API 순회, 중복 수집, 원본 가격 조정은 하지 않는다.
- 내보내기 보고서는 기존 수집 조회 범위 전체를 사용하는 별도 경로다. 이번 화면 면적 필터가 보고서에 적용된다고 주장하지 않으며, 보고서 연동 확장은 별도 검증 대상이다.

## 6. 검증 시나리오
- 59㎡·84㎡·121㎡가 섞인 가상 자료에서 84㎡ 선택 시 카드/차트/목록이 같은 행만 사용.
- 총액 ↔ ㎡당 ↔ 3.3㎡당 전환 시 주표시 단위와 표본 건수 일치.
- 84.97㎡/84.99㎡ 묶음, 다섯 개 이상 면적대, 자동선택 동률, 전체 면적 혼합 안내.
- 1건, 2건, 0건, 누락 월, 취소 거래, 동일 최신일 여러 거래, 면적 미확인.
- 62건 가상 페이지 자료의 10행/5번호·마지막 페이지·필터/정렬 초기화.
- 320·360·390·768·1280px에서 요약이 차트 위에 있고 가로 넘침이 없는지 확인.
- 화면에서 API 추가 호출이 없고, 실 수집 JSON 검증과 가상 UI 테스트를 구분한다.
