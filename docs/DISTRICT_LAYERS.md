# 지도 구역계 레이어 (2026-11-08)

## 사용
지도 오른쪽 위 `구역계`로 켜기/끄기, `구역 목록`으로 유형별 필터와 현재 화면 결과를 확인합니다. 확대 수준 13 이상에서 화면 사각형과 교차하는 구역을 조회합니다. 지도 이동은 350ms 지연 처리하며 이전 요청을 취소합니다.

기존 필지 클릭은 그대로 유지됩니다. 구역 목록을 클릭하거나 `구역 선택 모드`를 켜면 구역 상세를 확인합니다. 이름, 유형, 진행단계, 원본 기준일, 고시번호는 제공된 속성에 있는 경우만 표시합니다. 조회 시각은 자료 기준일과 별도입니다.

## 제공 경로와 검증 범위
- 지구단위계획: VWorld Data API `LT_C_UPISUQ161`, JSONP 또는 로컬 서버 프록시.
- LH 사업지구: VWorld Data API `LT_C_LHZONE`, JSONP 또는 로컬 서버 프록시.
- 도시주제도: VWorld NED WFS `getCtySpceWFS`, 안내 기본 레이어 `dt_d029`. EPSG:3857 좌표로 요청합니다. 이 레이어가 모든 재개발 정비구역을 포함한다고 보장하지 않습니다.
- 정적 Pages에서 NED WFS는 직접 fetch하므로 공급기관의 CORS/응답 형식 지원이 필요합니다. 실패 시 해당 종류를 `자료 미확인`으로 표시합니다.
- 본 작업의 실제 공급기관 요청은 개발 환경과 GitHub Actions 모두 연결 실패했습니다. 단위·브라우저 테스트는 합성 GeoJSON fixture 기반이며 실제 구역 수신, 전국 범위 완전성, 최신 고시 반영을 증명하지 않습니다.
- 후보지/공람안 경계, 구역명 별칭, 사업단계 데이터베이스는 추가하지 않았습니다. 공식 근거 없는 경계와 진행단계를 생성하지 않습니다.
- 지번 전체의 편입/제척 판정 기능이 아닙니다. 고시 도면·조서를 최종 확인해야 합니다.

## 외부 네이버 부동산
현재 지도 중심 및 선택 필지 좌표로 `new.land.naver.com/houses?ms=위도,경도,줌` 링크를 만듭니다. 새 `fin.land.naver.com` URL의 불투명 center 토큰을 추정하거나 타사 데이터를 수집하지 않습니다. 좌표 생성은 테스트하였으나 네이버 최종 리디렉션/동일 위치 표시와 개별 필지 실거래 조회는 검증되지 않았습니다.

## 데이터·오류 처리
Polygon/MultiPolygon과 내부 제외 영역을 보존합니다. 화면 중심점이 아닌 BBOX를 조회합니다. 페이지 제한, 일부 수신, 공급기관 오류를 표시하며 오류를 0건으로 바꾸지 않습니다. 이름표는 중첩을 줄이고 구역 상세는 textContent로 렌더링합니다. 원천 도형 파일을 저장소로 복사·가공·재배포하지 않습니다. 서비스 운영자는 공급 API 및 데이터의 이용조건을 확인해야 합니다.

## 개발
`node scripts/install-districts.mjs --write`는 기존 네 파일의 알려진 위치에만 연결 코드를 삽입하는 멱등 설치 도구입니다. 예상 코드가 달라졌으면 중단합니다. 테스트된 결과 파일은 CI가 기능 브랜치에 저장하므로 main에서 별도 설치는 필요 없습니다.

`npm test`: 기존 회귀 테스트와 10개 구역계 테스트.
`node scripts/districts.browser.mjs`: Playwright가 설치된 환경에서 합성 도형 표시, 상세, 링크 좌표, 표시 전환, 모바일 범위, 오류 후 잔여 도형 제거 확인.
