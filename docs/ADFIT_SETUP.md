# 카카오 AdFit 운영

<!-- SOFTM-ADFIT-DOCS START 날짜:20261012 : 돌봄한눈의 광고 운영 기준을 토지한눈 패널 구조에 맞게 기록 -->

운영 매체는 `https://tojihannun.designboard.net`이며, 좁은 검색·상세 패널 안에서 잘리지 않는 320×100 배너만 사용합니다. 광고 단위는 성과와 장애를 지면별로 구분할 수 있도록 재사용하지 않습니다.

| 광고 단위 이름 | 광고 단위 코드 | 규격 | 위치 | 설정 키 |
| --- | --- | --- | --- | --- |
| 토지한눈_검색패널_320x100 | `DAN-dLSnDNaQBJXV18Kx` | 320×100 | 첫 화면 검색 패널의 빠른 찾기 아래 | `searchPanel` |
| 토지한눈_필지상세_하단_320x100 | `DAN-JNXyM9bPPPuvtJVr` | 320×100 | 필지 상세의 공식 안내 아래 | `parcelDetail` |

2026년 10월 12일 카카오 AdFit에 `토지한눈` Web 매체(`NAk`, `tojihannun.designboard.net`)를 도구·생산성 카테고리로 등록하고 위 두 단위를 발급했습니다. 두 단위는 소재 새로고침 60초, 텍스트 단독 소재 허용, 테두리·대체 광고·실 소재 노출 중단 미설정입니다.

발급한 `DAN-...` 값은 루트의 `adfit-config.js`에 입력합니다. 값이 비어 있거나 형식·규격·가용 폭이 맞지 않으면 광고 영역을 표시하지 않습니다. 검색 패널 광고는 화면 가까이에 왔을 때, 필지 상세 광고는 실제 상세 화면을 연 뒤에만 한 번 요청합니다. SDK 오류나 30초 내 광고 프레임 미생성 시 빈 지면을 제거합니다.

Android 앱은 자체 Google AdMob을 사용합니다. WebView User-Agent의 `AdMobNative/1`을 웹 런타임이 감지해 카카오 AdFit 요청을 막으므로 두 광고 SDK가 같은 화면에서 중복 노출되지 않습니다.

단위 재발급 시 AdFit의 같은 Web 매체에서 320×100 배너를 만들고 각 설정 키의 ID만 교체합니다. 두 지면에 같은 ID를 넣지 않으며, 변경 후 일반 브라우저와 Android WebView를 각각 확인합니다.
