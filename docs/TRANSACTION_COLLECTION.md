# 전국 거래자료 수집·정적 배포

## 범위와 제약
- 본수집은 정식 공공데이터 API와 **사용자가 제공한 공식 XLSX/CSV**를 처리한다. 웹 자료제공 화면을 크롤링하지 않는다.
- 국토부 공개안내 https://rt.molit.go.kr/pt/info/info.do?mobileAt= 에서 대량·반복 이용은 공공데이터포털을 이용하도록 안내하고 자동 추출을 제한한다. 파일 자동 다운로드를 구현·완료했다고 보고하지 않는다.
- 아파트, 연립·다세대, 단독·다가구, 오피스텔, 분양·입주권, 상업·업무, 토지, 공장·창고의 매매 8종 및 제공되는 주거형 전월세 4종을 별도 stream으로 관리한다. API 이용승인은 계정에 따라 다르며 미승인 유형은 오류로 표시한다.
- 2006년 매매, 2007년 6월 분양·입주권, 2011년 전월세부터 실행일 현재 계약월까지 작업을 계획한다. 최신 계약일이 모두 신고·공개됐다는 뜻은 아니다.
- 공식 행정코드에서 현행 지역을 읽는다. 폐지 코드는 별도로 보존하며 과거 행정구역의 자동 대응 관계를 추정하지 않는다. 기본 계획은 **현행 코드 기준**이며 이것만으로 전국 역사적 구역 이력까지 완전 확보했다고 주장하지 않는다.

## 실행
```sh
python3 scripts/rtms/collector.py --mode import
python3 scripts/rtms/collector.py --mode refresh --max-tasks 96
python3 scripts/rtms/collector.py --mode backfill --max-tasks 96
python3 scripts/rtms/collector.py --mode build
```
선택 필터 `--districts 41210,44210`, `--streams rowHouse-sale,apartment-rent`를 지원한다. 인증은 서버 환경의 `MOLIT_API_KEY`로만 전달하며 URL·키를 로그에 쓰지 않는다.
`data/transactions/inbox/README.md`의 범위 명세와 원본 파일을 함께 추가하면 검증 후 반입한다. 실제 공식 파일 미반입과 parser 단위 테스트 성공은 구분한다.

## 안정성
- 월 단위 모든 페이지의 응답 코드·건수·시군구·계약월을 검증한 뒤 gzip 원본을 원자적으로 교체한다. 오류/중단은 기존 정상 자료를 지우지 않는다.
- 동일 내용의 거래가 여러 번 신고돼 있을 수 있어 임의 중복 제거하지 않는다. 원본 multiset 비교의 추가·사라짐은 정정/취소로 단정하지 않는다. 공식 취소표시는 따로 센다.
- 429와 호출한도 응답은 첫 실패에 종료한다. 실행당 요청·시간·업무량 상한과 순차 호출 간격을 둔다.
- 최신화는 최근 3개월을 재확인한다. 과거 정정의 완전한 반영을 보장하지 않으며 과거 파일 재반입/구간 재검증이 필요하다.
- 원본 `segments/시군구/stream/계약월.json.gz`, 서비스 파일 `published/시군구/법정동-stream-분할.json[.gz]`. 한 법정동의 확보 연도를 묶어 조회한다.
- 공개 지번 미확정 자료에 필지 좌표나 PNU를 추정하지 않는다. 공간 좌표 색인은 아직 제공하지 않는다.
- 앱에 직접 연결된 정적 실거래는 기존 **매매 UI**다. 전월세 자료는 수집·현황·정적 파일까지 제공하지만 전월세 화면은 별도다.

## 실행과 배포
- `Collect transaction sources`: 매시 17분 미확보 작업 제한 수집, 매일 04:00 KST 최근 자료 재확인, 파일 반입 push 및 수동 실행.
- 실행 상한에 도달해 정상 종료해도 **전국 수집 완료가 아니다**. 다음 실행은 정상 저장된 구간을 건너뛴다.
- GitHub bot의 데이터 커밋만으로 push 배포가 재실행되지 않는 문제를 피하려고 배포는 수집 workflow 완료 이벤트도 받는다.
- `data-status.html`은 실제 게시 manifest와 공개 GitHub Actions 실행 상태를 별도로 읽는다. 미수집/오류는 정상 0건이 아니다.
- API 전체량을 한꺼번에 Git에 쌓지 않도록 요청 예산을 제한한다. 규모가 커지면 동일 manifest 계약을 유지하며 별도 객체 저장소로 분리해야 한다.

## 검증
Python 표준 라이브러리 기반 parser/수집 테스트, Node 회귀 테스트, desktop/mobile 현황 및 실제 저장자료 lookup 브라우저 검증을 제공한다. 원본 확보, 정적 파일 생성, 테스트, 배포 성공은 별도 상태다.
