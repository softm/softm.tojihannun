# 실거래 상세 UI (2026-11-10)

- 부동산 유형별 **매매** 자료를 표시한다. 수집기에 전월세 스트림이 있어도 이 화면에서 지원한다고 표시하지 않는다.
- 선택 지번 / 같은 법정동 비교를 분리한다. 지번 비공개 자료는 비교에만 포함하며 선택 지번 일치를 추정하지 않는다.
- 필터 및 새로고침은 게시된 정적 파일을 읽는다. 공공 API 추가 조회는 내부 `collectedOnly:false` 명시적 요청 외에는 하지 않는다.
- 실거래 탭에는 수집 현황 링크, 수집 자료 배너, 일부 기간 확보 상태, 확보 계약월 목록, 자료 갱신일, 전체 이력 아님 문구를 표시하지 않는다. 수집 범위와 실패 상태의 내부 데이터 모델은 유지하며 별도 운영 현황 페이지와 수집기는 변경하지 않는다.
- 조회기간은 전체 기간 / 최근 N개월 / 연도로 표시한다. 전체 기간은 조회 가능한 자료의 필터이며 전국·전기간 수집 완료를 뜻하지 않는다.
- 거래 조회 중 / 읽기 오류 / 조건에 맞는 조회 내역 없음은 간단한 문구와 필요한 중단·재시도 버튼으로 표시한다. 오류를 거래 0건으로 바꾸거나 미확보 자료를 완전한 이력으로 변경하지 않는다.
- 거래 목록은 계약일·금액·면적·층·단가를 표시한다. 정렬은 로컬에서 수행하며 20건씩 늘려 보인다. 200건 표시 제한은 없다.
- 월별 차트는 거래 목록 아래 접힌 상태로 배치한다. 상위 팝업의 세로 스크롤을 사용하고 새로운 고정 레이어를 만들지 않는다.
- 새 모듈과 CSS는 실거래 탭에 한정한다. 수집기·원본 데이터·지도 구역계 코드는 변경하지 않는다.

검증: `npm test`, Python 수집 회귀 테스트, `npm run build`, `PLAYWRIGHT_MODULE=... node scripts/transaction-ui.browser.mjs`.
브라우저 검증은 저장소의 실제 게시 거래와 운영 HTML/CSS를 사용하되 지도·광고·외부 API를 차단한다. 성공·기간 변경·읽기 오류·빈 결과에서 수집 안내가 노출되지 않는지 확인한다. 실기기 GPS·실제 운영 URL 검증을 대신하지 않는다.
