# 실거래 상세 UI — 수집 자료 기준 (2026-11-10)

- 부동산 유형별 **매매** 자료를 표시한다. 수집기에 전월세 스트림이 있어도 이 화면에서 지원한다고 표시하지 않는다.
- 선택 지번 / 같은 법정동 비교를 분리한다. 지번 비공개 자료는 비교에만 포함하며 선택 지번 일치를 추정하지 않는다.
- 필터 및 새로고침은 게시된 정적 파일을 읽는다. 공공 API 추가 조회는 내부 `collectedOnly:false` 명시적 요청 외에는 하지 않는다.
- 수집 범위의 최소/최대 계약월과 **실제로 확보한 계약월 목록**을 함께 제공한다. 중간 공백이 있는 범위를 연속 수집으로 표현하지 않는다. 전체 이력 완료라고 표시하지 않는다.
- 상태를 로딩 / 읽기 실패 / 수집 범위 미확인 / 일부 기간 확보 / 선택 기간 확보로 구분한다. 계약월 확보와 필지 거래 발견은 서로 다른 상태다.
- 거래 목록은 계약일·금액·면적·층·단가를 표시한다. 정렬은 로컬에서 수행하며 20건씩 늘려 보인다. 예전 200건 표시 제한을 제거했다.
- 월별 차트는 거래 목록 아래 접힌 상태로 배치한다. 상위 팝업의 세로 스크롤을 사용하고 새로운 고정 레이어를 만들지 않는다.
- 새 모듈과 CSS는 실거래 탭에 한정한다. 수집기·원본 데이터·지도 구역계 코드는 변경하지 않는다.

검증: `npm test`, Python 수집 회귀 테스트, `npm run build`, `PLAYWRIGHT_MODULE=... node scripts/transaction-ui.browser.mjs`.
브라우저 검증은 저장소의 실제 게시 거래와 운영 HTML/CSS를 사용하되 지도·광고·외부 API를 차단한다. 실기기 GPS·실제 운영 URL 검증을 대신하지 않는다.
