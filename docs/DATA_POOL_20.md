# 20개 데이터 저장소 용량 풀

- 001~010의 담당 지역, 체크포인트, 수집 담당은 변경하지 않는다.
- 011~020은 지역 미배정 증설 대기 레포다. 같은 데이터를 중복 수집하지 않는다.
- 게시 용량 계획 상한 합계는 20GB, 900MB 분할 기준 합계는 18GB다. 보장된 호스팅 용량이나 현재 데이터량을 뜻하지 않는다.
- readiness.json에는 API 키 존재 여부와 Pages 설정 확인 결과만 기록한다. 키 원문·길이·해시·접두어는 기록하지 않는다.
- 키 등록 확인은 국토부 API 활용승인 성공을 뜻하지 않는다. Pages 설정 확인과 실제 배포 성공도 구별한다.
- 기존 서비스 조회와 JSON은 그대로 보존한다. 담당 이관과 최종 체크포인트 검증 없이 지역 API 수집을 활성화하지 않는다.
